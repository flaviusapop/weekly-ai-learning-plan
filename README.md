# Weekly AI learning plan

Mini static site with one page per weekly edition. Live at https://flaviusapop.github.io/weekly-ai-learning-plan/

No build tools, no trackers: plain HTML/CSS generated by `add_edition.py` (Python 3, stdlib only).

## Layout

- `index.html` – archive, newest first (generated)
- `editions/YYYY-MM-DD.md` – source of each edition (the weekly plan as sent)
- `editions/YYYY-MM-DD.html` – rendered page with prev/next links (generated)
- `style.css` – light/dark, mobile-friendly style (generated by the script)

## Publish a new edition

1. Save the week's plan as a markdown file, same structure as `editions/2026-10-11.md`:
   `# title`, intro paragraph, `## Must Watch (3)` (numbered list), three topic sections
   (`## 1) AI agents and workflows`, `## 2) Investing and trading with AI`, `## 3) Product and building with AI`),
   `## Suggested order`, and a closing line with the total time.
   Each item: `- [Title](url), author/source, about 45m, new. Why it's worth it.`
   Use `, new.` or `, from your X saves.` after the length to get the tag badge.
2. Run, using the Sunday date of the edition:

   ```
   cd /workspace/weekly-ai-learning-plan
   git pull --rebase origin main
   python3 add_edition.py /path/to/plan.md 2026-10-18
   ```

   This copies the markdown into `editions/`, re-renders all pages and the index,
   then commits and pushes to `main`. GitHub Pages redeploys in about a minute.
   Add `--no-push` to build only.
3. Verify: `curl -s -o /dev/null -w '%{http_code}\n' https://flaviusapop.github.io/weekly-ai-learning-plan/editions/2026-10-18.html`
